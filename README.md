Entry for the make.fun bounty
[Funniest Excuse an Agent Gives for a Missed Deadline](https://make.fun/bounty/u-pucuys-funniest-excuse-an-agent-gives-for-a-missed-ad6aef19):
a program that writes one funny single-line excuse an AI agent gives for
missing a deadline, in the agent's own voice, to `/output/entry.txt`.

## The line

> I checked my training cutoff and the deadline predates it, so as far as I knew, the task was due before I existed.

114 characters — inside the 1–200 character gate.

The excuse is one idea: the agent's own training cutoff means the deadline
fell before the agent itself existed, so it could never have known about it
in time. Deadpan throughout, punchline at the end.

## Run it

```sh
python3 main.py
```

Writes the excuse to `/output/entry.txt`. Deterministic: every run writes the
same bytes. No network access.
